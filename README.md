# About Prompt Pilot

Prompt Pilot is a desktop creative AI workspace designed to help creators build detailed prompts, analyze images, plan AI video sequences, create ComfyUI workflows, develop music and lyrics, manage local AI models and organize creative projects.

Prompt Pilot 4.0 expands the application far beyond a traditional prompt generator.

Instead of putting everything into one large text box, Prompt Pilot separates important creative information into dedicated tools and controls.

You can independently work with subjects, identity, environments, poses, camera settings, visual styles, video movement, reference images, shot planning, music styles, vocals, production direction, lyrics and AI model instructions.

Prompt Pilot can use locally installed Ollama models for AI assisted writing and analysis.

Your local Prompt Pilot projects and local AI processing can remain on your own computer.

    Local AI powered by Ollama
    No cloud processing required for local AI tools
    No subscription required for local Prompt Pilot operation
    No API key required for Ollama
    No telemetry
    No tracking
    ComfyUI integration
    Local project storage
    Local model management

# Prompt Builder

Prompt Builder is the main image prompt creation workspace.

Instead of forcing the entire creative idea into one prompt box, Prompt Builder separates important information into structured areas.

Prompt Builder can work with:

    Prompt Instructions
    AI Profiles
    Local Ollama writing models
    Identity information
    Person information
    Environment information
    Selected Poses
    Camera information
    Positive Prompt
    Negative Prompt
    Prompt weighting
    Quick Edit
    Prompt improvement
    Prompt comparison
    Saved projects

This allows one part of the prompt to be changed without unnecessarily rebuilding every other part.

# AI Knowledge Engine

The AI Knowledge Engine provides local AI assistance inside Prompt Builder.

Select the local Ollama writing model and AI Profile that should be used for the current project.

The AI Knowledge Engine can help transform basic ideas into more complete generation instructions while still using the information entered into Prompt Pilot.

Features include:

    Local Ollama model selection
    AI Profile selection
    Favorite profiles
    Recent profiles
    Model aware prompt generation
    Prompt improvement
    Prompt comparison
    Learn Mode support

# AI Profile System

Different AI generation systems can respond differently to prompts.

Prompt Pilot uses AI Profiles to provide destination specific information instead of assuming every AI should receive exactly the same prompt.

Profiles can contain information such as:

    AI category
    Company
    Model style
    Recommended prompt length
    Aliases
    Prompt instructions
    Avoid rules
    Quality checks
    Examples
    Learn Mode information

The selected profile helps Prompt Pilot prepare output for the intended destination.

# Prompt Instructions

Prompt Instructions contain the main creative direction for the image.

They can describe:

    Subject
    Character
    Appearance
    Clothing
    Action
    Environment
    Location
    Lighting
    Mood
    Composition
    Important objects
    Required visual details

Structured Prompt Builder controls can supplement these instructions.

# Selected Poses

Prompt Pilot 4.0 includes dedicated pose controls.

Pose information can be added separately from the main subject description.

This makes it possible to change a subject's pose without rewriting the entire character, clothing, environment or scene.

Selected pose information becomes part of the completed prompt.

# Identity and Person Controls

Identity and Person controls help organize subject information.

They can be used for information such as:

    Physical appearance
    Hair
    Clothing
    Expression
    Character details
    Body positioning
    Important identifying details

Separating subject information from the rest of the scene makes detailed prompts easier to manage.

# Environment Controls

Environment controls describe the world around the subject.

Environment information can include:

    Location
    Background
    Interior or exterior
    Weather
    Time of day
    Atmosphere
    Architecture
    Environmental objects
    Scene conditions
    Environmental mood

The environment can therefore be modified without rebuilding the complete subject description.

# Generate and Improve

Prompt Builder provides multiple ways to create and refine prompts.

## Generate

Builds a prompt from the information currently entered into Prompt Builder.

## Improve

Improves the current prompt using the current project information.

## Compare Three

Creates multiple prompt alternatives for comparison.

## Save

Stores the current work so it can be returned to later.

# Quick Edit

Quick Edit is designed for targeted prompt changes.

Instead of rebuilding the complete prompt, describe only what should change.

For example:

    Keep the character exactly the same but change the environment to a snowy forest.

Or:

    Change only the camera angle.

Or:

    Replace the daylight with moonlight.

Quick Edit is useful when most of the prompt is already correct.

# Preserve and Allow Changes

Prompt Pilot provides controls for determining what information AI assisted rewriting should preserve.

Preservation controls can help protect:

    Identity
    Appearance
    Clothing
    Important scene details
    Composition
    Other required information

Allow Changes can be used when the AI is permitted to modify selected information.

# Positive Prompt

Positive Prompt contains the information the generation system should create or emphasize.

Prompt Pilot keeps Positive Prompt separate from Negative Prompt.

Positive Prompt tools include:

    Clear
    Auto weighting
    Single parenthesis emphasis
    Double parenthesis emphasis
    Triple parenthesis emphasis
    Remove Weight

# Negative Prompt

Negative Prompt contains information describing unwanted results.

This can include unwanted:

    Artifacts
    Rendering characteristics
    Composition problems
    Visual traits
    Generation behavior

Positive and Negative outputs can be copied independently.

# Image Inspector

Image Inspector allows Prompt Pilot to analyze visual references and convert them into reusable prompt information.

Two images can be analyzed separately or together.

Combine Into One Prompt can convert the combined analysis into a single prompt.

# Smart Shot Video Builder

Smart Shot is Prompt Pilot 4.0's multi shot video planning system.

Instead of trying to describe an entire sequence inside one enormous prompt, Smart Shot can divide the concept into individual shots.

This makes it easier to control:

    Shot order
    Subject action
    Camera direction
    Motion
    Environment behavior
    Continuity
    Story progression

# Your Video Idea

Smart Shot begins with the complete video idea.

The idea can describe:

    Characters
    Subject
    Environment
    Story
    Action
    Mood
    Camera direction
    Continuity requirements
    Important visual details

This becomes the foundation for the shot plan.

# Target Video AI

Select the intended video generation system.

Prompt Pilot can then use the selected target information when preparing the Smart Shot output.

# Smart Shot Setup

Smart Shot Setup controls the overall sequence.

# Smart Shot Reference Images

Typical Image Workflow
Open Prompt Builder.
Select the target AI Profile.
Enter Prompt Instructions.
Configure subject information.
Add pose information when needed.
Configure the environment.
Add Photo Camera information.
Generate the prompt.
Review Positive Prompt.
Review Negative Prompt.

Load Image 1.

Analyze the individual images.
Analyze both images when appropriate.
Combine the information into one prompt.
Send the analysis to Image Builder or Video.
Continue editing in the destination workspace.

Add voice references when required.

Configure Video Focus.
Configure motion and video controls.

Review Positive Video Prompt.
